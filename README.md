# 📘 Guia de Cursos Online e Gratuitos em TI

## 🚀 Objetivo

Este repositório reúne **cursos, plataformas e recursos gratuitos de aprendizado em Tecnologia da Informação (TI)**.

O objetivo é orientar estudantes, iniciantes e profissionais que desejam desenvolver ou aprimorar suas habilidades técnicas por meio de conteúdos disponíveis online, priorizando recursos gratuitos e de qualidade.

## 🎯 Como Usar Este Guia

1. **Escolha uma trilha** de acordo com seu objetivo profissional.
2. **Defina uma rotina de estudos**, reservando algumas horas por semana.
3. **Combine teoria e prática**, aplicando os conhecimentos adquiridos em projetos.
4. **Construa um portfólio**, utilizando plataformas como GitHub ou GitLab.
5. **Documente sua evolução**, registrando projetos, certificados e novas habilidades.
6. **Explore diferentes áreas**, caso ainda esteja decidindo qual carreira seguir dentro da tecnologia.
